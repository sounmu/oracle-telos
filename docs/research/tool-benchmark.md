# 기존 도구의 기준과 UI 벤치마크

목적: 사람들이 이미 아는 방식에 맞춰 온보딩 부담을 줄이기 위해, 기존 도구가 무엇을 기준으로 유사성을 보여 주고 어떤 화면 구성을 쓰는지 정리한다. 공식 문서와 검색 요약을 바탕으로 했고, 확인하지 못한 항목은 비워 두었다.

## 1. 도구별 기준과 화면

| 도구 | 유사성의 기준 | 화면 구성 | 우리가 가져올 점 |
|---|---|---|---|
| [Connected Papers](https://www.connectedpapers.com/about) | 동시 인용 + 서지 결합. 약 5만 건 후보 중 상위 수십 건 | 기준 논문(시드) 하나 중심, 힘 기반 배치로 비슷한 논문끼리 모임. 노드 크기는 인용 수, 색은 발표 연도 (2차 자료 기준) | 시드 중심 구성. "이 점을 기준으로 보기" 진입이 가장 직관적이다 |
| [Litmaps](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10403115/) 계열 리뷰 | 인용 관계 기반 | x축 발표일, y축 인용 밀도, 노드 크기는 영향력. 시드 지도와 여러 시드의 발견 지도 제공. 지도끼리 겹쳐 보기 | 시간축을 두면 기술 흐름이 보인다. 여러 시드 비교는 세션 개념과 맞닿는다 |
| [ResearchRabbit](https://aarontay.substack.com/p/researchrabbits-2025-revamp-iterative) (블로그 요약) | 인용 네트워크와 의미 유사도를 함께 사용 | "비슷한 연구", "이전 연구", "이후 연구" 모드를 나눔 | 추천 종류를 모드로 나누는 방식은 필터 설계에 참고할 만하다 |
| [ETO Map of Patents](https://eto.tech/tool-docs/mop) | 제목·초록, 특허 간 인용, CPC/IPC 텍스트를 함께 사용해 클러스터 생성 | 클러스터 지도 | 클러스터 기준을 여러 신호로 섞는 방식이 참고가 된다 |
| [Questel 랜드스케이프 맵](https://intelligence.help.questel.com/en/support/solutions/articles/77000450043-understand-and-use-a-landscape-map) | 특허 밀도 | 점이 많은 곳이 높은 산처럼 보이는 지형도 | 우리의 밀집도 배경과 가장 가까운 시각 언어다. 위험도 배경을 지형처럼 보이게 하는 방향과 맞다 |
| [PatSnap Eureka](https://help.patsnap.com/hc/en-us/articles/8765035408669-Eureka-Analysis) | 의미 검색, 이미지 검색, 인용 지도 | 3D 랜드스케이프, 차트형 분석, 인용 지도 | 확인된 범위에서 인용 지도가 있다. 3D는 온보딩에 부담이 될 수 있다 |

## 2. 공통 패턴 (기존 사용자가 기대할 것)

1. 시작점(시드) 하나를 정하면 주변이 펼쳐진다.
2. 점을 누르면 옆 패널에 메타데이터와 "왜 가까운지"가 나온다.
3. 색은 상태나 시기, 크기는 영향력이나 인용 수로 쓴다. 범례를 항상 보인다.
4. 필터와 모드를 상단에 두고, 기본값은 가장 단순한 보기로 둔다.

## 3. 우리 UI에 적용할 안 (제안)

- 기본 보기는 지도 하나로 두고, 검색이나 세션 시작 시 시드 점을 지정한다. Connected Papers 방식과 맞춘다.
- 점 색은 승인·거절·심사중으로 기존 범례를 유지한다. 크기는 출원일 등으로 바꾸지 않고 기본 크기를 유지한다.
- 점을 누르면 "왜 가까운가"를 한 줄로 보여 준다. 예: 같은 CPC 분류, 제목·초록 의미 유사도 0.72.
- 관계선은 기본 꺼짐으로 두고, 켜면 같은 분류 관계만 옅게 표시한다. 이웃 수는 2개를 넘지 않게 한다.
- 위험도 배경은 Questel처럼 지형 느낌의 옅은 물들임으로 둔다.

## 4. 확인이 필요한 사항

- Inciteful 추천 방식, Google Patents 유사 문서 방식, Lens 클러스터 방식은 공식 문서를 직접 확인하지 못했다.
- 위 검색 요약은 블로그와 마케팅 페이지를 포함하므로, 발표 전에 공식 문서로 한 번 더 확인해야 한다.
