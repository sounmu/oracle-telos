# 시연 세션 입력 문장

`pnpm dev:demo`로 띄운 뒤 홈 아래 입력창에 그대로 붙여 넣고 "템플릿으로 바꾸기" → "탐색으로 →" 순서로 진행한다.
세 문장 모두 템플릿 네 칸이 자동으로 채워지고, 각 세션의 상세 확인 특허 4건이 모두 결과에 들어오며, 검증 단계에서 그 주제의 실제 분쟁 사례가 가장 위에 연결된다.

## 세션 1 · 의료용 필러 (제조공법)

> 피부과에서 쓰는 성형용 필러를 PLA 미세입자로 만들고 싶어요. 고분자를 에틸렌 카보네이트에 녹인 뒤 차가운 용액에 분사해 얼리는 냉동 분사 공법으로 입자를 만들 계획인데, 이미 비슷한 제조 방법 특허가 있는지 궁금해요.

| 칸 | 자동 입력 |
|---|---|
| 핵심 기술 | PLA 미세입자, 에틸렌 카보네이트, 냉동 분사 |
| 대상 고객 | 피부과 |
| 우려 분야 | 제조공법 |

- 결과 약 30건, 바임 특허 4건 순위 1·3·4·8
- 연결 사례: 리젠바이오텍 vs 바임 (겹친 결과 23건), 판결 2025허10641

## 세션 2 · 이차전지 분리막 (코팅 소재·공정)

> 전기차 배터리 회사에 납품할 분리막을 개발하려고 해요. 폴리에틸렌 다공성 막 위에 세라믹 무기물 입자와 바인더를 섞어 코팅해서 고온에서도 열수축이 적고 전극과 잘 붙게 만드는 방식인데, 이런 코팅 분리막에서 특허 분쟁 위험이 어디에 있는지 알고 싶어요.

| 칸 | 자동 입력 |
|---|---|
| 핵심 기술 | 분리막, 무기물 입자, 바인더 |
| 대상 고객 | 전기차 배터리 회사 |
| 우려 분야 | 코팅 소재·공정 |

- 결과 약 70건, LG화학·신왕다 특허 4건 순위 9·11·45·49 (위쪽은 이들을 인용한 실제 분리막 특허)
- 연결 사례: LG에너지솔루션 vs 신왕다 (겹친 결과 40건)

## 세션 3 · OLED 화소 배열 (화소 배열 구조)

> 스마트폰 제조사에 공급할 OLED 패널, 그러니까 유기 발광 표시 장치의 화소 배열을 새로 설계하고 있어요. 녹색 서브 화소를 가상의 사각형 중심에 두고 빨강과 파랑 서브 화소를 꼭짓점에 배치해서 해상도를 높이는 구조인데, 기존 화소 배열 특허와 얼마나 겹치는지 확인하고 싶어요.

| 칸 | 자동 입력 |
|---|---|
| 핵심 기술 | OLED, 화소 배열, 녹색 서브 화소 |
| 대상 고객 | 스마트폰 제조사 |
| 우려 분야 | 화소 배열 구조 |

- 결과 약 32건 (실제 13·더미 19), 삼성디스플레이·BOE 특허 4건 순위 8·11·14·19
- 연결 사례: 삼성디스플레이 vs BOE (겹친 결과 20건)

## 문장을 바꿀 때
- "~에 납품할", "~에 공급할", "~에서 쓰는", "~를 위한" 표현이 있으면 대상 고객이 채워진다.
- "코팅·분리막", "화소", "공법·제조" 같은 단어가 우려 분야를 정한다.
- 핵심 기술은 `src/lib/explore.ts`의 용어 사전(`TECH_TERMS`)에서 먼저 고른다.
- "성형용 필러", "유기 발광 표시 장치"는 바임 2022 특허와 삼성 10-1427593을 결과에 넣기 위해 넣은 표현이다. 빼면 그 특허가 빠질 수 있다.
