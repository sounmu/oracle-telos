# 의사결정 아카이브 (D16~)

이전 항목(D1~D11)은 대화 기록의 표를 따른다. 실험 관련 항목(위험도 계산식, 관계선 데이터 소스 확인, KIPRIS 추가 호출)은 실험이 끝날 때까지 이 표에 넣지 않는다 (`docs/design/experiment-manual`은 `docs/research/`에 있음).

| 항목 | 질문 | 검토한 대안 | 결정 | 근거 | 기술적 어려움 | 결과 | 상태 |
|---|---|---|---|---|---|---|---|
| D16. 사업 단계 체계 | 특허 기반 사업 런칭의 단계를 어떻게 나눌까? | 4단계(탐색·검증·리스크·포지셔닝) / 대상 기준 유형(A~D) | 시간 순서의 4단계 × 판단 대상 5개로 MECE 구성. 이후 포지셔닝을 탐색에 합쳐 3단계로 줄임 | 중복이 적고 사업가 여정과 맞음. 포지셔닝은 탐색의 빈 자리 기능과 겹침 | "찾기"가 탐색과 지형 조회로 갈라지는 문제 | 기능 6개를 3단계에 배치 | 확정 |
| D17. 홈 화면 구조 | 첫 화면에 무엇을 둘까? | 현황 대시보드 / 지도 중심 / 랜딩 페이지 | 지도 중심. 현황 대시보드는 두지 않음. 왼쪽에 세션 목록, 지도 아래에 입력창과 기능 막대 | 그림 메모의 "홈 = 전체 DB 지형도" | 지도 위 여러 패널이 겹침 | 홈은 지도, 세션은 대화 단위 | 확정 |

| D20. 세션 기본 조회 | 한 번에 몇 건을 어떤 순서로 볼까? | 전체 / 200건 / 유사도순 | 기본은 최신 출원 200건. 개수는 50·200·전체에서 고름. 유사도순은 검색 결과가 있을 때만 | 지도 성능과 탐색 속도의 균형 | 검색 점수가 없을 때 정렬 대체 | 구현 완료 | 확정 |
