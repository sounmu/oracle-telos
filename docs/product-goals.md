# Telos 최종 서비스 목표

작성일: 2026-10-16
상태: 장기 제품 방향. 현재 구현 완료를 뜻하지 않는다.
해커톤 범위: [해커톤 MVP 목표](hackathon-mvp.md)

## 1. 서비스 정의

기술 기반 스타트업이 자기 기술 주변의 특허, 기술 분쟁 사례, 관련 논문을 기술 중심으로 탐색하고 비교하는 서비스다. 평상시에는 기술 탐색·확장·연구 도구로, 분쟁 우려가 생기면 로펌·변리사 상담 전 자료를 정리하는 1차 판단 도구로 사용한다.

법률 정보보다 기술 정보를 앞에 둔다. 분쟁의 승패뿐 아니라 어떤 기술 요소를 다퉜고, 양측 기술의 차이와 유사성 중 무엇이 판단을 갈랐으며, 이후 기술과 제품이 어떻게 바뀌었는지를 설명한다.

논문 연결은 원래 최종 구상에 포함된 확장 후보로 보존하되, 해커톤에서는 제외한다. 장기 포함 여부는 추후 재검토한다.

## 2. 대상과 사용 시점

주 대상은 기술 기반 스타트업의 CTO·연구소장, CEO, 연구원·개발자다. 예비 창업자와 대학·연구소 스핀오프도 포함한다. 투자사 심사역은 장기 확장 대상이다.

| 사용 시점 | 입력과 기대 결과 |
|---|---|
| 평상시 연구·기술 확장 | 기술 설명으로 선행 특허와 인접 기술을 탐색 |
| 경고장·소송 발생 | 상대 특허번호·회사명으로 특허 상태, 심판 이력, 유사 분쟁의 판단 이유 확인 |
| 투자·상장·M&A 실사 전 | 자사 특허·제품 소개서·IR 자료로 주변 특허와 관련 사례 정리 |
| 신제품 출시·해외 진출 전 | 제품 기술 요소에 관련된 특허·사례 탐색. 해외 데이터는 확장 단계 |
| 핵심 인력 영입·퇴사 | 회사·발명자 관계와 관련 특허, 인력 이동에서 시작된 분쟁 탐색 |

## 3. 핵심 기능

### 입력과 탐색

- 기술 설명 문장, 상황을 묻는 질문, 특허번호·회사명, 기술 카테고리, 제품 소개서·IR 업로드를 지원한다.
- 도메인과 기술 중심으로 검색한다. 초기 도메인은 바이오·의료미용이다.
- 권리 범위가 겹칠 가능성을 검토할 특허와 기술 확장에 참고할 특허를 구분해 제공한다.
- 기술 지도에서 제품군, 기술 요소, IPC·CPC 분류를 기준으로 주변 특허를 탐색한다.
- 의미 유사도, 인용 관계, 출원인·발명자 네트워크를 활용한다. 각각의 관계와 근거를 구분한다.

### 기술 비교와 분쟁 사례

- 사용자 기술과 특허의 공통 요소·차이·추가 확인 사항을 근거와 함께 비교한다.
- 분쟁 사례는 기술 쟁점, 절차, 결과, 판단 이유, 기술적 영향, 사업 영향을 중심으로 보여준다.
- 회피 설계, 제품 버전 변경, 특허 무효·축소, 귀속 변경, 크로스 라이선스 등 분쟁 이후 변화를 추적한다.
- 협업·투자 협의·공모전·납품 과정의 아이디어 분쟁을 포함하고, 공개 범위와 NDA·회의록·제공 자료 목록 등 기록 준비를 안내한다.

### 근거와 분석

- 문장별로 특허 원문·판결문·심결문·공시 등 출처를 연결하고 확인되지 않은 내용은 명시한다.
- AI가 판단 이유와 기술 원리 설명 초안을 작성하고 변리사·연구자가 검수한다.
- 사례를 분쟁 계기·절차·결과·기술적 영향으로 분류한다. 통계에는 표본 범위·선정 기준·누락 가능성을 표시한다.
- 논문 연결을 재추진할 경우 특허의 비특허문헌, 국내외 기술 논문을 연결한다.
- 위험도 수준과 근거 목록은 장기 검토 기능이다. 기술 유사도를 침해 확률이나 등록 가능성으로 취급하지 않으며, 법적 제공 범위와 평가 기준을 먼저 검토한다.

## 4. 데이터와 연결 구조

국내 특허·분쟁 데이터로 시작하고 해외로 확장한다.

| 데이터 | 수집 후보와 주요 항목 |
|---|---|
| 특허 | KIPRIS Plus: 청구항 전문, 초록, 인용·피인용 문헌, 출원인, 발명자, IPC·CPC |
| 심판 | KIPRIS Plus 심판사항: 무효심판·권리범위확인심판 이력, 심결문 접근 경로 |
| 판례·판결문 | 국가법령정보 Open API, 대법원 종합법률정보, 판결서 인터넷 열람 |
| 공시 | DART: 소송 공시, 증권신고서 투자위험요소, 감사보고서 주석 |
| 행정 제재 | 공정위 사건정보와 기술유용 의결서 |
| 해외 확장 | CourtListener, USPTO 등 국가별 원자료 |

특허번호, 출원인명, 심판번호, 사건번호로 연결한다. 특허번호가 없는 영업비밀 사례는 도메인·기술 태그로 연결하며, 태그 연결을 직접적인 사건 연관성으로 표현하지 않는다.

API 제공 항목, 이용 조건, 호출 한도, 원문 접근 가능 여부는 구현 시 공식 자료로 확인한다. 거절결정서 원문 없이 거절 이유를 추정하지 않는다.

| 근거·검수 | 출처, 해당 페이지·문단, 확인일, 검수 상태, 미확인 사항 |

## 6. 조사 배경과 사례 후보

사용자 조사에서는 사업 확장·상장·인수와 분쟁이 겹친 사례, 해외 절차에서 판매가 제한된 사례, 분쟁 이후 기술이 변경된 사례가 제시됐다. 이를 서비스 필요성의 조사 가설로 보존한다.

- 펩트론·지투지바이오: 인력 이동, 특허 무효 절차, 특허 소멸과 상장 시점.
- 3Shape·메디트: 구강스캐너 분쟁, 국가별 판매 제한, 인수와 합의 시점.
- Bio-Rad·10x Genomics: 금지명령, Next GEM 재설계, 상장과 크로스 라이선스.
- 메디톡스·대웅제약·에볼루스: ITC 절차, 수입 제한과 합의.
- 세원셀론텍·유바이오시스: 영업비밀 보호기간과 금지명령 범위.
- True Wearables, LG에너지솔루션·SK이노베이션, 듀폰·코오롱: 판매 제한 또는 인력 이동 관련 추가 사례.

이 문서는 제품 범위를 정리한 것이며 개별 사건의 날짜·금액·결론을 독립 검증한 조사 보고서가 아니다. 사용자 조사에 포함된 국내 7건·해외 11건 등의 표본 통계는 원자료와 선정 기준을 확인하기 전 일반적인 발생률로 사용하지 않는다.

기존 조사 자료는 `00_참고자료_판례특허_검색사이트_API`, `01_기술분쟁_사례`, `02_아이디어탈취_사례`를 참고 자료명으로 관리한다. 해당 자료 파일이 이 저장소에 있다는 뜻은 아니다.

## 7. 수익 구조

- 스타트업 직접 구독: 평상시 기술 탐색·연구 수요.
- 투자사·액셀러레이터 계약: 포트폴리오 지원과 실사 전 탐색.
- 공공기관·창업·IP 지원사업 연계: 지원 대상 기업에 서비스 제공.

## 8. 추후 결정할 사항

- 위험도 제공의 법적 범위, 평가 기준과 설명 방식.
- 하급심 판결문·심결문 확보와 이용 조건.
- AI 설명의 검수 기준, 검수 인력과 비용.
- 국가별 데이터 접근성 및 해외 확장 순서.
- 논문 연결의 장기 포함 여부.
- 제한된 사례 표본으로 통계를 제공할 때의 해석 범위.
